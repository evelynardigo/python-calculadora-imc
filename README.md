# ⚖️ Calculadora de IMC

Projeto desenvolvido em **Python** para praticar cálculos matemáticos, entrada de dados e estruturas condicionais.

A aplicação solicita o **peso e a altura do usuário**, calcula o IMC e apresenta uma classificação de acordo com o resultado obtido.

## 🎯 Objetivo

Praticar os fundamentos de Python por meio de uma aplicação simples e interativa.

O programa é capaz de:

- Receber peso e altura;
- Calcular o IMC;
- Apresentar o resultado com duas casas decimais;
- Classificar o resultado de acordo com faixas predefinidas.

## 🛠️ Tecnologias

- Python 3
- PyCharm

## 📚 Conceitos praticados

- `input()`
- Conversão de dados com `float()`
- Operações matemáticas
- Estruturas condicionais (`if`, `elif`, `else`)
- Formatação de números

## ⚙️ Fórmula utilizada

```text
IMC = peso / altura²
```

## 💻 Exemplo

```text
Qual é o seu peso em kg? 70
Qual é a sua altura? 1.75

O valor do IMC é 22.86
A situação da pessoa é:
PESO IDEAL
```
